# 江慕晨（muchen）ST TavernPet

此套件含兩種透明背景精靈圖：

- `spritesheet.png` / `spritesheet.webp`：8 欄 × 9 列，供目前的 SillyTavern TavernPet 擴充直接使用。
- `spritesheet-extended.png` / `spritesheet-extended.webp`：8 欄 × 11 列、`spriteVersionNumber: 2`，額外包含完整 16 向注視動畫。

每格尺寸為 192 × 208 px。標準圖集總尺寸為 1536 × 1872 px，v2 圖集總尺寸為 1536 × 2288 px。

若已將 `muchen` 資料夾放在 TavernPet 擴充的 `assets/pets/` 下，可在「自訂圖集」欄位填入：

`/scripts/extensions/third-party/SillyTavern-TavernPet/assets/pets/muchen/spritesheet.png`

角色規格：深棕側分髮、金色下垂眼、右眼角下方淚痣、銀色耳飾、制服、奶茶色下垂狗耳及同色狗尾巴；沒有髮夾或附著式髮飾。

`qa/` 內附標準與 v2 圖集驗證、16 向語意、盲測及連續性報告。
